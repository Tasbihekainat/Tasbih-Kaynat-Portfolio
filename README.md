# Tasbih Kaynat — AI Creative Portfolio

A single-page portfolio showcasing AI-generated image and video work (campaigns, product shots, brand mascot, and motion pieces).

**Live site:** enable GitHub Pages on this repo (see below) and it'll be published at
`https://<your-github-username>.github.io/<repo-name>/`

## Contents

- `index.html` — the portfolio page
- `assets/` — images and video used in the portfolio

## Publish with GitHub Pages

1. Push this repo to GitHub (see steps below).
2. On GitHub, go to **Settings → Pages**.
3. Under **Build and deployment → Source**, choose **Deploy from a branch**.
4. Set branch to `main` and folder to `/ (root)`, then **Save**.
5. GitHub will give you a live URL in a minute or two — that's the link to share with recruiters.
